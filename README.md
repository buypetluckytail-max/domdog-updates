# DOM-DOG — канал обновлений test-candidate

Открытый репозиторий источника обновлений DOM-DOG (этап 2.17).

- `test-candidate/manifest.json` — манифест канала;
- `test-candidate/manifest.json.sig` — подпись манифеста (RSA-PSS SHA-256, ключ DOM-DOG);
- раздел Releases `v<версия>` — пакеты обновления (ZIP).

Манифест и пакет публикует конвейер `desktop-windows-publish-217.yml` репозитория `domdog`.
Вручную файлы не редактируются: без закрытого ключа подпись не пройдёт проверку, и обновление будет отклонено.
